01.Can I use One, Flow and Cloud separately?

Yes. Each product works on its own and has its own free plan. When you use them together, accounts, permissions, data and billing are shared automatically.

02.Is my data used to train AI models?

No. Your content and usage data are never used to train models — ours or any model provider’s. Data is encrypted in transit and at rest.

03.Do I need to know how to code to use Flow?

No. Flow has a visual builder and a template library for common workflows. Developers can add code steps or manage workflows through the API.

04.Which models does the AI Gateway support?

The gateway gives you one API for leading hosted models as well as your own self-hosted models. You can route by cost, latency or quality, and set fallbacks per route.

05.How does billing work for Cloud?

Cloud is usage-based: you pay for requests, tokens and compute seconds, with a free monthly allowance. Spend limits and alerts can be set per project.

06.Can I migrate from another tool?

Yes. One imports from common drives and wikis, and Flow can import workflows from popular automation tools. Business and Enterprise plans include migration help.

07.Do you offer private deployment?

Yes, on the Enterprise plan. We offer dedicated instances and deployment in your own cloud account to meet compliance and data residency requirements.
